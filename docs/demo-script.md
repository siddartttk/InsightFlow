# 80-second screen recording plan

Use the running demo at `/overview`. Prepare the browser at desktop width and keep the API running. Show the historical sample label throughout. No fictional client outcomes or predictions.

| Time | Action | Narration |
| --- | --- | --- |
| 0–10 s | Open Overview and show the dataset label | “InsightFlow turns retail transaction data into a clear analytical workspace. This demo uses an attributed historical invoice sample.” |
| 10–23 s | Point to gross/net sales, orders and AOV. Choose Last 30 days, then Apply with a specific range if desired | “These metrics use documented calculations. Orders count invoices, and net sales accounts for returns.” |
| 23–35 s | Inspect Revenue; switch Weekly/Monthly and open numerical chart data | “The same filters update the revenue trend, order volume and basket-value analysis. Exact values are available alongside the chart.” |
| 35–47 s | Navigate to Products, search a product and sort the units/revenue column | “Product rankings show what sells, how many units move and each product’s contribution.” |
| 47–60 s | Navigate to Customers and show segment table/methodology | “Customer segments use transparent recency, frequency and monetary rules. This describes activity, without claiming to predict churn.” |
| 60–70 s | Open Insights and expand View calculation | “Every observation links back to its calculated evidence.” |
| 70–80 s | Open Reports and download a product or segment CSV | “Filtered reports are ready to share. Compatible CSV data can use the same workflow in temporary private sessions when enabled.” |

Optional separate recording: download the import template, upload it and navigate by sidebar links to the resulting analytics. Reloading the page clears the browser token; preserve Link navigation during this demonstration.

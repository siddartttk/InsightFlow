# InsightFlow customization service

## Proposed engagement

A scoped retail analytics implementation: inspect the client's transaction exports, agree metric definitions, map compatible fields, adapt the dashboard, calibrate descriptive customer segments, provide useful report exports, and deliver setup/documentation and a recorded demonstration. This is a proposed service package, not an existing paid client outcome.

| Customer | Adaptation | Additional development |
| --- | --- | --- |
| Retail store | POS export mapping, store/date filters, gross/net definitions | Multiple stores, staff-level permissions, returns reconciliation, costs/tax treatment |
| Online seller | Ecommerce CSV mapping, SKU/product analysis, market reports | Automated Shopify/WooCommerce connectors, multi-currency conversion, shipping/discount accounting |
| Small agency | Brand, repeatable reporting, client-specific definitions | Authenticated client workspaces, access control, durable storage and scheduled reports |
| Consulting firm | Agreed KPIs, segment calibration, CSV reporting | Cohort analysis, PDF templates, report scheduling and approved distribution workflows |

## Define the scope before quoting

Agree input format, currency, date interpretation, return semantics, expected data size, required metrics, user roles, hosting, retention and handover. The MVP assumes GBP and one transaction schema, processes uploads in memory, has no authenticated accounts, and uses illustrative RFM thresholds. Those limits must be understood before accepting confidential business records.

Deliverables can include a customized dashboard, mapping/preparation script, tested calculations, deployment configuration, operational documentation and a user walkthrough. Hosting, domain registration, maintenance and security review are separate responsibilities and should be stated in the contract. Do not sell the current demonstration as an audited accounting system or a predictive churn product.
